# מה הקובץ `ideal` עושה?

בריפו הזה אין קובץ בשם `ideal` עצמו — `ideal` הוא שם הפרויקט/התיקייה.

הפרויקט מכיל דפי HTML סטטיים לתהליך הרשמה ותשלום של IDEAL TOURS:

- `form.html` — טופס הרשמה ראשי.
- `payment.html` — דף השלמת תשלום.
- `success.html` — דף אישור לאחר השלמת התהליך.
- `mk.html`, `negina.html` — דפי וריאציה/נחיתה נוספים לתהליך.

כלומר, תפקיד הפרויקט `ideal` הוא לספק את ממשק המשתמש (Frontend סטטי) של תהליך ההרשמה והתשלום.
